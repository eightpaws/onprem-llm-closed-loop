# Замеры этого стенда

Здесь лежат JSON-файлы от `scripts/bench.sh`: дата, хост, модель, токены в секунду для prefill и decode.

Подробные карточки экспериментов с командами, версиями и сырыми данными лежат отдельно: [v100-field-notes](https://github.com/eightpaws/v100-field-notes).

## Сводка правил из замеров

| Правило | Числа | Источник |
|---|---|---|
| `num_batch=2048` вместо дефолта | x3 против 128, +31% против дефолта Ollama | V100-10 |
| Контекст 32k для 14B | 64k не влезает ни при какой точности KV | V100-02 |
| MoE вместо плотной модели | 24,5 tok/s против 3,0 tok/s | V100-37 |
| Префиксный кэш | 95 мс против prefill 1697 токенов | V100-11 |
| Патчи volta-fa | +7,4% decode вместо обещанных +34-45% | V100-16 |
| DRY sampler | около -3% скорости, эффекта нет | V100-24 |
| Квантование KV `q8_0` | обязательно вместе с FlashAttention | V100-02 |

## Как читать эти числа

Каждая цифра получена на одной карте Tesla V100-SXM2 16 ГБ в виртуалке Proxmox. Это не бенчмарк вендора и не пересказ чужого README. Где замер сделан один раз, это указано в карточке: повторяемость не выдумывается.
